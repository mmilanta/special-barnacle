# Libre Baskerville

Variable WOFF2 fonts served by Google Fonts, downloaded 2026-11-02:
https://fonts.google.com/specimen/Libre+Baskerville

The regular and italic faces support weights 400–700. The original Latin and
Latin Extended subsets and their Unicode ranges are preserved. Files are served
locally without requests to Google at runtime. The regular Latin face is preloaded;
other subsets and italics load only when needed.

Source CSS:
https://fonts.googleapis.com/css2?family=Libre+Baskerville:ital,wght@0,400..700;1,400..700&display=swap
